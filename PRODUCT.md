## Platform

web

## Product Purpose

Realtime Voice Changer converts live audio with a selected voice model. The workspace lets users choose and manage models, adjust the conversion, route input and output, and monitor performance while working.

## Operating Context

The web client supports browser audio and server audio. Model management includes local upload, sample download, and model editing. The workspace also provides voice settings, recording, and advanced controls.

## Brand Commitments

The redesign covers the main workspace and its model and settings dialogs. The confirmed visual reference is Fastwork.com's seller portfolio.
